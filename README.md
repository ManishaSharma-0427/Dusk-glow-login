# Dusk-glow-login
Dusk Glow Login is an atmospheric web login page inspired by a dim room at dusk. It features a charcoal background, glassmorphism card, and a minimalist lamp casting a golden glow. A unique right-click and drag-down gesture triggers a brighter, hidden pop-up login, turning a basic form into an elegant, interactive experience.
